# 支離滅裂おみくじ　公開までの手順

みんなが追加した「一言のパーツ」を保存する場所（スプレッドシート）を作る手順です。上から順番に進めてください。

- **パソコンが必要です**（Apps Script の画面はスマホだと操作しにくいです。最後の確認だけはスマホでOK）
- かかる時間：15〜20分くらい
- 使うもの：Google アカウント、GitHub アカウント
- 第1回（思い出マップ）のスプレッドシートとは **別に、新しく** 作ります。第1回のものは触りません

設定が終わるまでのあいだも、おみくじは引けます（最初から入っているパーツだけで動きます）。パーツの追加は「デモモード」になり、追加した言葉はそのブラウザの中でだけ使われます。

---

## ステップ1　スプレッドシートを作る

1. https://sheets.google.com を開く
2. 「空白のスプレッドシート」（大きな「＋」）をクリックする
3. 左上の「無題のスプレッドシート」をクリックして、名前を **支離滅裂おみくじ** に変える

表には何も書かなくて大丈夫です。`parts` シートと見出しは、最初にパーツが追加されたときに自動で作られます。

> このスプレッドシートは誰とも共有しないでください。

## ステップ2　Apps Script のエディタを開く

1. スプレッドシートの上のメニューから **拡張機能** を押す
2. **Apps Script** を押す（新しいタブでエディタが開きます）
3. 左上の「無題のプロジェクト」をクリックして、名前を **支離滅裂おみくじ** に変えて「名前を変更」を押す

## ステップ3　コードを貼り付けて保存する

1. 別のタブで、GitHub のこのファイルを開く
   `drives/02-omikuji/gas/Code.gs`
2. ファイル右上の **コピーボタン**（四角が2つ重なったアイコン「Copy raw file」）を押す
3. Apps Script のエディタに戻り、最初から入っている `function myFunction() { ... }` を **全部消す**
4. コピーしたコードを貼り付ける
5. **保存**（フロッピーディスクのアイコン、または Ctrl＋S／Mac は ⌘＋S）を押す

## ステップ4　ウェブアプリとして公開する（デプロイ）

1. エディタ右上の青い **デプロイ** ボタンを押す
2. **新しいデプロイ** を押す
3. 左側「種類の選択」の横の **歯車アイコン** を押して、**ウェブアプリ** を選ぶ
4. 次のように設定する

   | 項目 | 設定 |
   |---|---|
   | 説明 | 第2回（なんでもOK） |
   | 次のユーザーとして実行 | **自分** |
   | アクセスできるユーザー | **全員** |

   「全員」にしないと、サイトを見た人がパーツを追加できません。

5. **デプロイ** を押す

## ステップ5　アクセスを許可する（警告が出ます）

初めてのときだけ、「このアプリにスプレッドシートを触らせていいですか？」と聞かれます。途中で **「Google はこのアプリを確認していません」** という警告が出ますが、自分で作ったアプリなので大丈夫です。

1. **アクセスを承認** を押す
2. 自分の Google アカウントを選ぶ
3. 「Google はこのアプリを確認していません」と出たら、左下の **詳細**（または「詳細を表示」）を押す
4. **支離滅裂おみくじ（安全ではないページ）に移動** を押す
5. 許可の内容が出るので **許可** を押す（チェックボックスがあれば全部にチェックしてから）

## ステップ6　ウェブアプリのURLをコピーして動作を確かめる

1. 「デプロイを更新しました」などの画面の **ウェブアプリ** の下にあるURLの **コピー** を押す
   - `https://script.google.com/macros/s/（長い文字列）/exec` のように、最後が **/exec** のURLです
2. そのURLをブラウザの新しいタブで開く
3. 次の文字が出れば成功です

   ```
   {"ok":true,"parts":{"itsu":[],"doko":[],"nani":[],"dounaru":[]}}
   ```

4. **【Claude Code に貼ってください】** このURLを Claude Code に送ってください。Claude Code が `storage.js` に設定して公開します
   （自分で設定する場合はステップ7へ。Claude Code にお願いした場合はステップ8へ）

## ステップ7　（自分で設定する場合）URLをサイトに設定する

1. GitHub で `drives/02-omikuji/storage.js` を開く
2. 右上の **鉛筆アイコン**（Edit this file）を押す
3. `const API_URL = '';` の行を探す
4. `''` の間にステップ6のURLを貼り付ける（`'` は消さない）

   ```js
   const API_URL = 'https://script.google.com/macros/s/（長い文字列）/exec';
   ```

5. 右上の **Commit changes...** を押す → 「Commit directly to the main branch」のまま **Commit changes** を押す

## ステップ8　スマホで確かめる

公開URL：https://wagomuchan.github.io/drive_coding1_claude/drives/02-omikuji/

1. 公開URLを開いて、下の **📜 今日の一言のパーツ募集中** を押す
2. 黄色い「デモモード」の帯が **出ていない** ことを確認する（出ていたら1〜2分待って読み込み直す）
3. 〈どこ〉を選んで、何か言葉を入れて **奉納する** を押す
4. スプレッドシートに `parts` シートができて、1行増えていれば完成です

## あとで知っておくと便利なこと

### 不適切な言葉を消したいとき

スプレッドシートの `parts` シートで、その行の行番号を右クリック → **行を削除**。次にページを開いた人から、おみくじに出なくなります。

### 言葉が増えて重くなってきたら

`Code.gs` の `const MAX_PER_KIND = 0;` を `500` などにすると、種類ごとに新しい順でその数までしか返さなくなります（0 は全部）。書き換えたら下の「Code.gs を書き換えたとき」の手順で新バージョンを出してください。

### Code.gs を書き換えたとき（大事）

保存しただけでは公開中のウェブアプリには反映されません。

1. **デプロイ** → **デプロイを管理**
2. 右上の **鉛筆アイコン**（編集）
3. 「バージョン」を **新バージョン** にする
4. **デプロイ**

（「新しいデプロイ」を選ぶとURLが変わってしまうので注意）

### つまずきやすいところ

| 症状 | 対処 |
|---|---|
| ステップ6でURLを開くとログイン画面やエラーが出る | ステップ5の許可が終わっているか。URLの最後が `/exec` か（`/dev` ではない） |
| 「社務所につながりませんでした」と出る | ステップ4の「アクセスできるユーザー」が **全員** か |
| デモモードの帯が消えない | `storage.js` の `API_URL` にURLが入っているか。保存後、数分待って読み込み直したか |
| コードを直したのに変わらない | 上の「Code.gs を書き換えたとき」で新バージョンを出したか |
| 「詳細」ボタンが見つからない | 警告画面の左下の小さい文字です。ブラウザの画面を広くすると見つけやすいです |

### このしくみについて

- `storage.js` に書いたウェブアプリのURLは誰でも見られます。追加の窓口なので問題ありませんが、スプレッドシート自体のURLは公開しないでください
- 連続追加のチェックはブラウザごとのランダムなIDで行う簡易的なものです
- 天気は Open-Meteo（登録不要・無料）から、ページを開くたびに取得しています
