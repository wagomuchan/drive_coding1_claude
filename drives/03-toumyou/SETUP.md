# 豆苗　公開までの手順

全国のみんなで共有する「豆苗パック」と「ランキング」を保存する場所（スプレッドシート）を作る手順です。上から順番に進めてください。

- **パソコンが必要です**（Apps Script の画面はスマホだと操作しにくいです。最後の確認だけはスマホでOK）
- かかる時間：15〜20分くらい
- 使うもの：Google アカウント
- 第1回・第2回のスプレッドシートとは **別に、新しく** 作ります。前のものは触りません

設定が終わるまでのあいだも、ページは「デモモード」で遊べます（そのブラウザの中だけで育ちます。デモでは1〜3分で育ちます）。

---

## ステップ1　スプレッドシートを作る

1. https://sheets.google.com を開く
2. 「空白のスプレッドシート」（大きな「＋」）をクリックする
3. 左上の「無題のスプレッドシート」をクリックして、名前を **豆苗** に変える

表には何も書かなくて大丈夫です。`畑`・`ユーザー`・`歴代チャンピオン` のシートは、最初にページが開かれたときに自動で作られます。

> このスプレッドシートは誰とも共有しないでください。

## ステップ2　Apps Script のエディタを開く

1. スプレッドシートの上のメニューから **拡張機能** を押す
2. **Apps Script** を押す（新しいタブでエディタが開きます）
3. 左上の「無題のプロジェクト」をクリックして、名前を **豆苗** に変えて「名前を変更」を押す

## ステップ3　コードを貼り付けて保存する

1. 別のタブで、GitHub のこのファイルを開く
   `drives/03-toumyou/gas/Code.gs`
2. ファイル右上の **コピーボタン**（四角が2つ重なったアイコン「Copy raw file」）を押す
3. Apps Script のエディタに戻り、最初から入っている `function myFunction() { ... }` を **全部消す**
4. コピーしたコードを貼り付ける
5. **保存**（フロッピーディスクのアイコン、または Ctrl＋S／Mac は ⌘＋S）を押す

> 最初に動作確認をしたいときは、保存する前に「育つ時間を短くして試す」（下のほう）を先に読んでください。

## ステップ4　ウェブアプリとして公開する（デプロイ）

1. エディタ右上の青い **デプロイ** ボタンを押す
2. **新しいデプロイ** を押す
3. 左側「種類の選択」の横の **歯車アイコン** を押して、**ウェブアプリ** を選ぶ
4. 次のように設定する

   | 項目 | 設定 |
   |---|---|
   | 説明 | 第3回（なんでもOK） |
   | 次のユーザーとして実行 | **自分** |
   | アクセスできるユーザー | **全員** |

   「全員」にしないと、サイトを見た人が収穫できません。

5. **デプロイ** を押す

## ステップ5　アクセスを許可する（警告が出ます）

初めてのときだけ、「このアプリにスプレッドシートを触らせていいですか？」と聞かれます。途中で **「Google はこのアプリを確認していません」** という警告が出ますが、自分で作ったアプリなので大丈夫です。

1. **アクセスを承認** を押す
2. 自分の Google アカウントを選ぶ
3. 「Google はこのアプリを確認していません」と出たら、左下の **詳細**（または「詳細を表示」）を押す
4. **豆苗（安全ではないページ）に移動** を押す
5. 許可の内容が出るので **許可** を押す（チェックボックスがあれば全部にチェックしてから）

## ステップ6　ウェブアプリのURLをコピーして動作を確かめる

1. 「新しいデプロイ」の画面の **ウェブアプリ** の下にあるURLの **コピー** を押す
   - `https://script.google.com/macros/s/（長い文字列）/exec` のように、最後が **/exec** のURLです
2. そのURLをブラウザの新しいタブで開く
3. `{"ok":true,"field":[{"g":10,"ok":true,...` のような文字がずらっと出れば成功です
4. スプレッドシートのタブに戻ると、`畑` シートに30行できています
5. **【Claude Code に貼ってください】** このURLを Claude Code に送ってください。Claude Code が `storage.js` に設定して公開します
   （自分で設定する場合はステップ7へ。Claude Code にお願いした場合はステップ8へ）

## ステップ7　（自分で設定する場合）URLをサイトに設定する

1. GitHub で `drives/03-toumyou/storage.js` を開く
2. 右上の **鉛筆アイコン**（Edit this file）を押す
3. `const API_URL = '';` の行を探す
4. `''` の間にステップ6のURLを貼り付ける（`'` は消さない）

   ```js
   const API_URL = 'https://script.google.com/macros/s/（長い文字列）/exec';
   ```

5. 右上の **Commit changes...** を押す → 「Commit directly to the main branch」のまま **Commit changes** を押す

## ステップ8　スマホで確かめる

公開URL：https://wagomuchan.github.io/drive_coding1_claude/drives/03-toumyou/

1. 公開URLを開く
2. 黄色い「デモモード」の帯が **出ていない** ことを確認する（出ていたら1〜2分待って読み込み直す）
3. 濃い緑の豆苗を指でなぞって、ブチッと収穫する
4. 1秒くらい待つと、スプレッドシートの `ユーザー` シートに自分の行ができて、`畑` シートの「収穫した人」が埋まっていれば完成です

## あとで知っておくと便利なこと

### 育つ時間を短くして試す

本番は1本ごとに1〜3時間で育ちます。動作確認のときは短くできます。

1. Apps Script のエディタで `Code.gs` の上のほうにある、この2行を探す

   ```js
   const GROW_MIN_MS = 1 * 60 * 60 * 1000;
   const GROW_MAX_MS = 3 * 60 * 60 * 1000;
   ```

2. 次のように書き換える（1〜3分になります）

   ```js
   const GROW_MIN_MS = 1 * 60 * 1000;
   const GROW_MAX_MS = 3 * 60 * 1000;
   ```

3. 保存して、下の「Code.gs を書き換えたとき」の手順で新バージョンを出す
4. 試し終わったら、同じ手順で元に戻す（`60 * 60` に戻す）

すでに収穫した豆苗は、収穫したときの時間で育ちます。すぐ全部育てたいときは、次の「豆苗を全部育ちきりに戻す」をしてください。

### 豆苗を全部育ちきりに戻す

`畑` シートの「育ちきる時刻」の列（C列）の2〜31行目を選んで、Delete キーで空にします。空のマスは「育ちきり」として扱われます。

### 不適切なニックネームを直したいとき

`ユーザー` シートの「ニックネーム」の列を書き換えます。10秒くらいで画面にも反映されます（その人のブラウザに残っている名前も、次に開いたときに直ります）。

### 月が変わったとき

毎月1日の0時（日本時間）をすぎて最初にだれかがページを開いたときに、先月の1位が `歴代チャンピオン` シートに自動で書き込まれ、ランキングがリセットされます。何もしなくて大丈夫です。

### Code.gs を書き換えたとき（大事）

保存しただけでは公開中のウェブアプリには反映されません。

1. **デプロイ** → **デプロイを管理**
2. 右上の **鉛筆アイコン**（編集）
3. 「バージョン」を **新バージョン** にする
4. **デプロイ**

（「新しいデプロイ」を選ぶとURLが変わってしまうので注意）

### （おまけ）シートの時刻を日本時間で表示する

スプレッドシートの **ファイル** → **設定** → 「タイムゾーン」を **(GMT+09:00) Tokyo** にして **設定を保存**。動きには関係ありません。見やすくなるだけです。

### つまずきやすいところ

| 症状 | 対処 |
|---|---|
| ステップ6でURLを開くとログイン画面やエラーが出る | ステップ5の許可が終わっているか。URLの最後が `/exec` か（`/dev` ではない） |
| 「畑につながりませんでした」と出る | ステップ4の「アクセスできるユーザー」が **全員** か |
| デモモードの帯が消えない | `storage.js` の `API_URL` にURLが入っているか。保存後、数分待って読み込み直したか |
| コードを直したのに変わらない | 上の「Code.gs を書き換えたとき」で新バージョンを出したか |
| 育つ時間を短くしたのに、なかなか育たない | 書き換える前に収穫した豆苗は前の時間のまま。「豆苗を全部育ちきりに戻す」をする |
| 「詳細」ボタンが見つからない | 警告画面の左下の小さい文字です。ブラウザの画面を広くすると見つけやすいです |
| iPhone で音が鳴らない | 本体横のスイッチ（消音モード）がオンだと鳴りません。ページ右上が 🔇 になっていないかも確認 |

### このしくみについて

- `storage.js` に書いたウェブアプリのURLは誰でも見られます。収穫の窓口なので問題ありませんが、スプレッドシート自体のURLは公開しないでください
- ユーザーはブラウザごとのランダムなIDで見分けています。機種変更やブラウザのデータ削除をすると、別の人として最初からになります
- ページを開いている人は10秒ごとに畑を読み直します（別のアプリに切り替えている間は止まります）
