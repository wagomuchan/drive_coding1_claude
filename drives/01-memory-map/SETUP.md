# ドライブの思い出マップ　公開までの手順

Google Apps Script を初めて使う人向けの手順です。上から順番に進めてください。

- かかる時間：20〜30分くらい
- 使うもの：Google アカウント、GitHub アカウント
- **パソコンのブラウザで作業するのがおすすめです**（Apps Script の画面はスマホだと操作しにくいです）

設定が終わるまでのあいだ、サイトは「デモモード」で動きます。デモモードでは、投稿はそのブラウザの中にだけ保存されて、他の人には見えません。

---

## ステップ1　スプレッドシートを作る

1. https://sheets.google.com を開く
2. 「空白のスプレッドシート」（大きな「＋」）をクリックする
3. 左上の「無題のスプレッドシート」をクリックして、名前を **ドライブの思い出マップ** に変える

表に何かを書き込む必要はありません。投稿用のシート（`posts`）と見出しは、最初の投稿があったときに自動で作られます。

> このスプレッドシートは誰とも共有しないでください。サイトからの読み書きは、ステップ4で作る窓口（ウェブアプリ）を通して行われます。

## ステップ2　Apps Script のエディタを開く

1. スプレッドシートの上のメニューから **拡張機能 → Apps Script** を選ぶ
2. 新しいタブで Apps Script のエディタが開く
3. 左上の「無題のプロジェクト」をクリックして、名前を **思い出マップ** に変える

## ステップ3　コードを貼り付けて保存する

1. 別のタブで、GitHub のこのファイルを開く
   `drives/01-memory-map/gas/Code.gs`
2. ファイル右上の **コピーボタン**（四角が2つ重なったアイコン「Copy raw file」）を押す
3. Apps Script のエディタに戻る。最初から入っている `function myFunction() { ... }` を **全部消す**
4. コピーしたコードを貼り付ける
5. **保存**（フロッピーディスクのアイコン、または Ctrl＋S／Mac は ⌘＋S）を押す

## ステップ4　ウェブアプリとして公開する（デプロイ）

1. エディタ右上の青い **デプロイ** ボタン → **新しいデプロイ** を選ぶ
2. 左側の「種類の選択」の横にある **歯車アイコン** → **ウェブアプリ** を選ぶ
3. 次のように設定する

   | 項目 | 設定 |
   |---|---|
   | 説明 | 第1回（なんでもOK） |
   | 次のユーザーとして実行 | **自分** |
   | アクセスできるユーザー | **全員** |

   「全員」にしないと、サイトを見た人が投稿できません（Google にログインしていない人も使えるようにするための設定です）。

4. **デプロイ** を押す

## ステップ5　アクセスを許可する

初めてのときだけ、Google から「このアプリにスプレッドシートを触らせていいですか？」と聞かれます。

1. **アクセスを承認** を押す
2. 自分の Google アカウントを選ぶ
3. 「Google はこのアプリを確認していません」という画面が出る。自分で作ったアプリなので大丈夫です
   - 左下の **詳細**（または「詳細を表示」）を押す
   - **思い出マップ（安全ではないページ）に移動** を押す
4. 許可する内容が表示されるので **許可**（チェックボックスがあれば全部にチェック）を押す

## ステップ6　ウェブアプリのURLをコピーして動作を確かめる

1. デプロイが終わると出る画面で、**ウェブアプリ** の下にあるURLの **コピー** を押す
   - `https://script.google.com/macros/s/（長い文字列）/exec` のように、最後が **/exec** のURLです
2. ためしに、そのURLをブラウザの新しいタブで開く
3. 次のような文字が出れば成功です

   ```
   {"ok":true,"posts":[]}
   ```

## ステップ7　URLをサイトに設定する

1. GitHub でこのファイルを開く
   `drives/01-memory-map/storage.js`
2. 右上の **鉛筆アイコン**（Edit this file）を押す
3. 次の行を探す

   ```js
   const API_URL = '';
   ```

4. `''` の間に、ステップ6でコピーしたURLを貼り付ける

   ```js
   const API_URL = 'https://script.google.com/macros/s/（長い文字列）/exec';
   ```

   `'` は消さないでください。

5. 右上の **Commit changes...** を押す → 「Commit directly to the main branch」のまま **Commit changes** を押す

## ステップ8　GitHub Pages で公開する

1. GitHub のこのリポジトリのページで **Settings**（歯車のタブ）を開く
2. 左のメニューから **Pages** を選ぶ
3. 「Build and deployment」を次のように設定する
   - Source：**Deploy from a branch**
   - Branch：**main** ／ フォルダは **/ (root)** → **Save**
4. 1〜3分待ってページを読み込み直すと、上に「Your site is live at …」と公開URLが出ます
   - このリポジトリの場合は **https://wagomuchan.github.io/drive_coding1_claude/** になります

## ステップ9　投稿してみる

1. 公開URLを開いて「ドライブの思い出マップ」を選ぶ
2. 「デモモードで動いています」の黄色い帯が **出ていない** ことを確認する（出ていたらステップ7をもう一度確認）
3. 「ここに行ったよ！を投稿する」を押して投稿する
4. スプレッドシートの `posts` シートに1行増えていれば完成です

## あとで知っておくと便利なこと

### 不適切な投稿を消したいとき

スプレッドシートの `posts` シートを開き、その行の行番号を右クリック → **行を削除** で消せます。サイトを読み込み直すと地図からも消えます。

### Code.gs を書き換えたとき（大事）

Apps Script のコードを直して保存しただけでは、公開中のウェブアプリには反映されません。次の手順で「新しいバージョン」を出してください。この方法ならURLは変わらないので、`storage.js` を直す必要はありません。

1. **デプロイ → デプロイを管理**
2. 右上の **鉛筆アイコン**（編集）
3. 「バージョン」を **新バージョン** にする
4. **デプロイ**

（「新しいデプロイ」を選ぶとURLが変わってしまうので注意してください）

### うまく動かないとき

| 症状 | 確認すること |
|---|---|
| 「投稿を読み込めませんでした」と出る | ステップ4で「アクセスできるユーザー」が **全員** になっているか。ステップ6のURLをブラウザで開いて `{"ok":true,...}` と出るか |
| ステップ6でURLを開くとログイン画面や「エラー」が出る | ステップ5の承認が終わっているか。URLの最後が `/exec` か（`/dev` ではない） |
| 黄色い「デモモード」の帯が消えない | `storage.js` の `API_URL` にURLが入っているか。保存（Commit）後、数分待ってから読み込み直したか |
| コードを直したのに変わらない | 上の「Code.gs を書き換えたとき」の手順で新バージョンを出したか |

### このしくみで知っておいてほしいこと

- `storage.js` に書いたウェブアプリのURLは、公開サイトなので誰でも見られます。投稿の窓口として公開しているものなので問題ありませんが、スプレッドシート自体のURLは公開しないでください
- 連投チェックはブラウザごとのランダムなIDで行っています。ブラウザのデータを消せばすり抜けられる、簡易的な対策です
- 位置情報を許可しなかった人には、IPアドレスから推測した大まかな位置を画面に表示するだけです。本人が確認・修正して「投稿する」を押すまで、どこにも保存されません
